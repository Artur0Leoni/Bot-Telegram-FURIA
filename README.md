# FURIA CS Telegram Bot

Bot de Telegram para fãs da FURIA Esports (CS2), com integração à API da HLTV. Receba atualizações automáticas sobre partidas, jogadores, estatísticas e muito mais diretamente no seu Telegram!

## Funcionalidades

-  Últimas notícias da FURIA via HLTV.org
-  Calendário de partidas futuras
-  Estatísticas dos jogadores
-  Votação de MVP (em desenvolvimento)
-  Comandos interativos no Telegram
